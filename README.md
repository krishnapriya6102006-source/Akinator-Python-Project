# Akinator – Python Person Guessing Game

## Project Description
This project is a simple Akinator-style guessing game developed using Python and the Pandas library.

The program asks the user a series of Yes/No questions and uses the answers to narrow down a list of possible people until it guesses the person selected by the user.

## Technologies Used
- Python
- Pandas
- Excel dataset (`people_25.xlsx`)

## Files in This Repository
- `akinator.py` – Main Python program.
- `people_25.xlsx` – Dataset containing people and their characteristics.
- `README.md` – Project description and instructions.

## How to Run the Project
1. Install Python.
2. Install Pandas using:

   `pip install pandas openpyxl`

3. Keep `akinator.py` and `people_25.xlsx` in the same folder.
4. Run the Python program:

   `python akinator.py`

## Working
The program displays a list of people, asks questions, filters the dataset based on the user's answers, and finally makes a guess.
